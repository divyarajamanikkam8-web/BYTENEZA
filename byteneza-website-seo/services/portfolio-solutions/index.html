FAQ

Common questions

Can I update the portfolio myself later?

Yes, an optional admin panel can be added so you can update sections like projects, skills or your resume without contacting us.

Is this a ready-made SaaS product?

No, each portfolio is built for you individually. The admin panel is an optional feature we build into your project, not a public self-serve platform.

Can I include a downloadable resume?

Yes, resume integration can be added as a downloadable file or a dedicated section.

Do you write my content for me?

We guide the structure and can help refine wording, but the content about your work and experience comes from you.
